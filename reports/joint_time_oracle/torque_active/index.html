Research question

When actuator torque becomes limiting, can changing robot configurations reduce trajectory execution duration beyond the best retiming of the original geometry?

The primary geometric contrast is B versus D, which uses the same independent timing solver on the original and jointly optimized paths. C is a local coupled optimizer, not a global oracle.
