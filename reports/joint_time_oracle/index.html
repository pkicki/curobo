Limitations

The baseline check is sampled only; the optimizer uses cuRobo RNEA and collision callbacks and has not been cross-checked against an independent engine. This debugging run used an external PyTorch device-property compatibility shim and is not a performance measurement. The generated cohort, multistart, adaptive verification, swept validation, control retiming experiment, detailed plots, and pilot and main studies remain incomplete.
